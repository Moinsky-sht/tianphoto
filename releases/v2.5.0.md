# Tianphoto v2.5.0

## 核心升级

### 1. SVG Composition Layer 正式成立

- 在 `content-template -> svg-grammar -> hero-scene -> mark-kind` 之后，新增 composition decision
- 根节点与图形节点稳定输出：
  - `data-reading-priority`
  - `data-svg-role`
  - `data-scene-density`
  - `data-mark-prominence`
- family 的图形差异不再只体现在“画什么”，还体现在“出现在哪里、以多大强度出现”

### 2. 阅读质感优先于更强图形表现

- hero scene 回到标题服务位：默认只占 hero 上半区视觉重心
- 阅读型 family 进一步压低 scene 节点数、对比度和体量
- section mark 改为题签化：小尺寸、弱填充、强轮廓
- inline infographic 改为解释型：如果不能脱离正文独立解释结构，就默认不出现

### 3. Position Rules 进入硬约束

- `hero-scene` 只能出现在 `wx-hero-mesh` 或 `tp-free-hero-art`
- `section-mark` 只能留在章节 heading meta 层
- `divider` 只能用于卡片之间，不得进入正文连续段落内部
- `inline-infographic` 必须是独立结构块，不得作为跨段装饰路径
- rule 模式会自动清理正文误放的 SVG；free 模式会移除不在允许区域的游离 SVG

### 4. Free 继续开放，但不再默许正文漂浮装饰

- 继续保持单 HTML 输出
- 不扩 preset 数量
- 不把 free 收成 rule-mode 镜像系统
- 允许自由构图，但显著 SVG 只能落在：
  - hero 区
  - divider 区
  - 独立说明区（panel / note / quote）

### 5. Doctor 升级为“语义 + 版式关系审校器”

- 新增命中：
  - 图形位置错误
  - 图形噪声过高
  - hero 抢阅读主重心
  - 正文穿越型装饰
  - free 模式中段大图 / 多个无关 SVG 容器
- 正常页面不应误报

## 产品边界不变

- 继续默认输出单个可编辑 HTML
- free 模式继续开放
- 本轮重点不是新增更多 SVG 类型，而是收紧位置、强度、节奏和审校
