# Tianphoto v2.1.1

`2.1.1` 不是继续加 preset，而是把 `2.1.0` 里已经搭好的“内容模板 + 设计审校 + 编辑器搭建”这条线真正收稳。

## 这次修了什么

### 1. 阅读型章节头重新定型

阅读型页面现在默认按两层结构生成：

- 第一层：`wx-section-index / wx-card-caption / wx-section-mark`
- 第二层：`h2`

这意味着：

- 大标题不再被编号、caption 或图形横向挤压
- `wx-section-mark` 不再像一个突兀的按钮
- 章节头更接近真正可读的移动端文章，而不是“组件拼装感”很重的 UI

### 2. 并列模块字号继续收紧

两列 `metric / compare` 卡片这次专门做了 typography 收口：

- `wx-metric-card strong` 默认更小
- `wx-compare-card h3` 默认更小
- 小卡片正文和说明的行高也一起收紧

目标很简单：让两列模块看起来像“信息模块”，而不是把 section 级大字硬塞进小格子。

### 3. 编辑器补上稳定的撤销 / 重做

上一轮已经有结构组件插入了，但还不够像真正能工作的编辑器。

这次补上了：

- 分类组件面板
- 稳定的 undo / redo 历史栈
- 新插入卡片可以撤销、重做

现在插入 `章节 / 摘要 / 引语 / 指标 / 对比 / 时间线` 之后，不会再出现“一插进去就只能硬改 DOM”的体验。

### 4. `/tp doctor` 继续升级

这次新增的设计审校重点是：

- 章节元信息有没有跑到 `h2` 后面
- metric 标题是不是太长，不适合小卡片
- compare 卡片标题是不是太长，不适合并列展示

也就是说，`doctor` 开始能抓住一部分“结构没错，但看起来还是丑”的问题。

## 这版的方向

`2.1.1` 的重点不是做更多风格，而是让默认输出更稳定：

- 让阅读型章节头更像真正的文章
- 让并列卡片更像信息模块
- 让编辑器更像能继续工作的页面搭建器
- 让设计 QA 不只是检查“有没有错”，也开始检查“是不是不顺眼”
