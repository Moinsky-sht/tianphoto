# Tianphoto v2.2.0

## 核心变化

- 新增 `src/design-system/css` 和 `src/editor` 源码层，正式进入“源码模块化、交付单 HTML”架构
- 新增 `scripts/build-assets.js`，可把源码层重新拼装为 `assets/article-theme.css`、`assets/editor-stable.js` 和兼容用 `assets/editor.js`
- `render-image.js` 接入构建层，每次生成前会先确保内联资产来自最新源码模块
- `tp-doctor` 升级为环境、结构、设计、架构建议四层输出，并检查构建产物是否与源码层同步
- 抽出共享 HTML 工具、内容模板规则和家族矩阵，为后续继续拆分 preset、template、validator 奠定基础

## 这版的意义

`2.2.0` 不是外观升级，而是底盘升级。

它的目标是：

- 继续保留单 HTML 的易交付、易分享、可继续编辑
- 同时让内部代码不再依赖超大单文件持续打补丁
- 为后续迭代 editor、template、doctor 和导出链路留出稳定接口

## 兼容性

- 对用户可见的 `/tp style / select / ui / doctor / version / update` 工作流不变
- 默认仍输出到 `~/Desktop/tianphoto-iterations`
- 浏览器内继续支持编辑、保存和导出 PNG
