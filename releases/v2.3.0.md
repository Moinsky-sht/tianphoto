# Tianphoto v2.3.0

## 核心升级

### 1. 模板注册表正式上线

- `section / summary / quote / metric / compare / timeline / image` 七类高频组件不再继续通过 JS 字符串硬拼。
- 编辑器内部改为模板注册表 + 克隆插入，后续新增组件和维护结构都更稳定。

### 2. 编辑器进入强约束稳定态

- 文本粘贴会自动净化成纯文本。
- 回车会生成标准化内容块，不再把随机 `div / br` 留进页面。
- 空标题、空段落和空说明位会保留最小可编辑空间，删空后仍然能继续输入。
- 图片继续保持页面内直接缩放，尺寸状态会跟着 HTML 一起保存。

### 3. 导出更适合公众号与飞书

- 导出面板默认提供两种格式：
  - `JPG（更轻，适合发布）`
  - `PNG（更稳，适合精修）`
- JPG 默认走高质量压缩档，适合公众号上传、飞书发送和常规传播。
- 切片逻辑加入安全切线扫描，优先避开图片、章节卡、摘要卡、引用卡和时间线项。

### 4. Doctor 继续升级

- `/tp doctor` 新增：
  - 模板注册表是否启用
  - 导出面板是否支持 JPG / PNG
  - 深层标题包裹结构检查
  - 非语义 inline SVG 过量检查
  - 脏 `div / br` 占位节点检查

## 对用户不变的部分

- 继续默认输出单个可编辑 HTML
- 继续可以浏览器内编辑、保存、导出
- 不改 `/tp` 主工作流，不要求额外分发文件夹

## 适合谁更新

- 如果你经常把内容发到公众号、飞书或群聊里，推荐更新到 `v2.3.0`
- 如果你已经开始重度使用编辑器插块、改图、改字，这一版也更稳
