# Tianphoto v2.4.0

## 核心升级

### 1. SVG 正式进入语义语法层

- 新增 `data-svg-grammar`、`data-hero-scene`、`data-mark-kind`
- family 不再只控制 heading system，也开始控制 hero scene、section mark、divider 和 infographic 的图形语法
- 15 个 family 的 SVG 差异开始按 `stroke_weight / corner_language / fill_strategy / density_level / geometry_bias` 五个维度拉开

### 2. Hero 不再回到通用 mesh

- `wx-hero-mesh` 改成受控 scene slot
- 会根据 `content-template + family + archetype` 自动选择更合适的 scene
- 同一篇内容换 family 后，hero 的形体语言会明显变化，而不只是换颜色
- scene SVG 会明确标记注册表来源，Doctor 能识别是否仍停留在通用 mesh

### 3. Section Mark 进入真正的语义匹配

- `wx-section-mark` 现在会根据 caption / h2 / 正文关键词推断 `mark-kind`
- 章节徽记不再只是通用小图标，而是报名、组织、任务、日程、资格、奖项、增长、方法、交付、风险、复盘等明确语义
- 阅读型 / 产品型 / 表达型三类 family 对同一语义会使用不同画法
- Doctor 会检查不同语义是否错误复用了同一个几何图形，只靠换色假装不同

### 4. Inline Infographic 收口

- `wx-inline-graphic` 不再鼓励自由插抽象装饰
- 只允许受控模板：流程、节点网络、对比、路径、证据栈、结构拆解
- `event-notice` 默认禁用 `wx-badge-art`
- 模板与 family 会共同限制可用的信息图种类和数量

### 5. Doctor 升级为 SVG 审校器

- 新增：
  - `mark-kind` 冲突检查
  - 重复徽记检查
  - hero scene 与 family 不匹配检查
  - inline infographic 缺少受控 kind 检查
  - section mark / infographic 复杂度过高检查

## 产品形态不变

- 继续默认输出单个可编辑 HTML
- 不扩 preset 数量，这一版重点是把图形质量和差异性做深
- 模型不再被鼓励自由写大段抽象 SVG，而是走“语义选择 + 语法配置 + 受控变体”
