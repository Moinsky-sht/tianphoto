# Tianphoto v2.1.0

这次 `2.1.0` 的重点，不是继续堆 preset，而是把 Tianphoto 往“更成熟的图文工作台”推进了一步。

## 核心升级

### 1. 内容模板层

页面现在除了 `preset / family / archetype` 之外，还会额外落到明确的 `content-template`：

- `event-notice`
- `weekly-report`
- `release-brief`
- `knowledge-article`
- `case-recap`

这意味着 Tianphoto 开始区分“这页到底是什么内容工作流”，而不再只是“选一个视觉皮肤”。

### 2. `/tp doctor` 升级为设计审校器

`/tp doctor` 不再只是检查版本和 Chrome。

现在它还会诊断：

- OpenClaw CLI 是否存在
- 当前环境是否能看到飞书相关能力
- 页面属于哪个内容模板
- 章节标题系统是否统一
- 每节是否只保留一个 `wx-section-mark`
- 是否还有旧的标题挂件或无语义图形
- 阅读型页面是否误用了 `wx-image-drop-zone`
- metric card 是否写得过长，不适合移动端扫描

### 3. 编辑器新增结构组件入口

浏览器内编辑器现在可以直接插入高频结构：

- `章节`
- `引语`
- `指标`
- `对比`
- `时间线`

其中 `引语` 还支持把当前选中的文字直接提炼成 `wx-quote-card`。

### 4. 回传状态更清晰

生成后的会话回传链路新增了明确的状态结果：

- 已回传成功
- 仅保存在本地

这样在 OpenClaw / 飞书 / generic 会话里都能更清楚地知道这次产物到底回去了没有。

## 设计方向

2.1.0 的方向是：

> 让 Tianphoto 更像“协作式图文工作台”，而不是只有生成能力的出图器。

重点在于：

- 更强的结构判断
- 更强的设计 QA
- 更强的浏览器内继续搭建能力
- 更清楚的会话闭环状态
